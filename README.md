# فروشگاه آنلاین اکسسوری و پنل مدیریت (Production-Ready)

یک فروشگاه آنلاین واکنش‌گرا (سازگار با وب و مینی‌اپ تلگرام) به همراه پنل مدیریت کامل، ساخته‌شده با **Java 21**، **Spring Boot 4.1**، **Thymeleaf** و **PostgreSQL**.

## ویژگی‌های کلیدی
- **گالری چندتصویری برای هر محصول (جدول جداگانه `product_image`):**
  - آپلود هم‌زمان چند عکس از دستگاه یا افزودن چند لینک مستقیم در فرم ایجاد و ویرایش محصول.
  - مدیریت تصاویر در پنل ادمین (انتخاب عکس اصلی/کاور و حذف تکی تصاویر با پاک‌سازی خودکار از فضای ذخیره‌سازی).
  - نمایش گالری تعاملی در صفحه جزئیات محصول همراه با تصاویر بندانگشتی، سوایپ لمسی، کلیدهای جهت‌دار و بزرگ‌نمایی (Lightbox).
- **ویترین فروشگاه:** جستجوی زنده (Debounce)، فیلتر دسته‌بندی، اسکرول بی‌نهایت (Infinite Scroll)، حالت Dark Mode و دکمه‌های ارتباط مستقیم با فروشنده.
- **پنل مدیریت:** داشبورد آمار، صفحه‌بندی، فیلتر، تغییر سریع موجودی (Stock Toggle)، و ورود دوگانه (رمز عبور یا کد یک‌بارمصرف OTP).
- **آماده برای پروداکشن:** اعتبارسنجی فرمت فایل‌های آپلودی و محافظت در برابر Path Traversal، مدیریت خطای متمرکز (`GlobalExceptionHandler`)، غیرفعال بودن OSIV، ایندکس‌های دیتابیس، Docker چندمرحله‌ای با کاربر غیرریشه (`appuser`) و `docker-compose.yml`.

## راه‌اندازی سریع در پروداکشن با Docker Compose
1. یک کپی از فایل نمونه متغیرهای محیطی بسازید و مقادیر واقعی خود (به‌ویژه `ADMIN_MOBILES`، `ADMIN_PASSWORD` و رمز دیتابیس) را وارد کنید:
   ```bash
   cp .env.example .env
   ```
2. پروژه و دیتابیس PostgreSQL را با یک دستور بالا بیاورید:
   ```bash
   docker compose up -d --build
   ```
3. فروشگاه روی پورت `8080` (یا پورت تنظیم‌شده در `APP_PORT`) در دسترس است:
   - ویترین فروشگاه: `http://YOUR_SERVER_IP:8080/`
   - پنل مدیریت: `http://YOUR_SERVER_IP:8080/admin`
   - صفحه ورود: `http://YOUR_SERVER_IP:8080/login`
